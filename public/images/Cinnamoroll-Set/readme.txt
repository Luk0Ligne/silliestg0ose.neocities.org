Cinnamoroll Set
===============

Author: Matthew Richards

This cursor set contains 17 cursors.

Files included:
  - cinnamoroll pen.cur
  - cinnamoroll person (2).cur
  - cinnamoroll person.cur
  - cinnamoroll working in background.cur
  - cinnamoroll precision.cur
  - cinnamoroll alternate select.cur
  - cinnamoroll unvailable.cur
  - cinnamoroll help select.cur
  - cinnamoroll link.cur
  - cinnamoroll move.cur
  - cinnamoroll text.cur
  - cinnamoroll vertical.cur
  - cinnamoroll horizontal.cur
  - cinnamoroll diagonal.cur
  - cinnamoroll pointer.cur
  - cinnamoroll diagonal 2.cur
  - cinnamoroll busy.cur

Installation:
  1. Right-click install.inf
  2. Select 'Install'
  3. Open Control Panel > Mouse > Pointers
  4. Select 'Cinnamoroll Set' from the Scheme dropdown
